1. Test Cases

Mỗi test case nên là một dòng trong Excel, gồm các cột:

Column	Nội dung
Test Case ID	Ví dụ TC-FP-001
Test Case	Tên/mục tiêu test case
API Put /update/product
Test Data	Dữ liệu request, ví dụ {"email":"test@eshop.com"}
Expected Result	Kết quả mong đợi, ví dụ response có resetToken dài 6 ký tự
Actual Result	Kết quả thực tế
Status	PASS / FAIL
